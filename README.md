# SubmodInt

## Dependencies

Install the dependencies with [uv](https://docs.astral.sh/uv): `uv sync --locked`, then
`source .venv/bin/activate`. The `dspn` task also needs
`uv pip install torchvision open_clip_torch huggingface_hub pyarrow scikit-learn wandb`.

## Dataset details

Datasets: `synthetic`: `fac-loc`, `g-cut`, `g-cut-8`, `int-2-1`, `log`, `log-det`, `log-times-log-det`,
`log-times-sqrt`, `sqrt`; `amazon`: `apparel`, `bath`, `bedding`, `diaper`, `feeding`, `gear`, `health`, `media`.
For the set-size table, add `--max-set-size N` (128, 256, 512, 1024 or 2048) to a `synthetic` run on `log-det`.

The synthetic data is generated by `run.py` and the Amazon data is in `source_real/`. The first `dspn` run downloads
ImageNet-100 (Hugging Face `clane9/imagenet-100`) and the CLIP weights into `DOWNLOAD_DIR`, and writes the CLIP
features to `FEATURE_DIR`.

## scripts/run.py

Trains and evaluates one model on one task:

```bash
python scripts/run.py synthetic --model SubmodInt --dataset g-cut
python scripts/run.py amazon --model SubmodInt --dataset gear
python scripts/run.py dspn --model SubmodInt --data DOWNLOAD_DIR --features FEATURE_DIR
```

## scripts/run_all.sh

Runs every model of a task:

```bash
bash scripts/run_all.sh synthetic synthetic-ablations synthetic-layers synthetic-set-size
bash scripts/run_all.sh amazon amazon-layers
DATA=DOWNLOAD_DIR FEATURES=FEATURE_DIR bash scripts/run_all.sh dspn
```
